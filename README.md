奶蛙鼠标指针 · Naiwa Cursors 🐸

- 17 种状态：覆盖正常选择、链接、文本、移动、缩放、不可用等常用场景。
- 动态加载：后台运行和忙碌状态配有循环动画。
- 三档尺寸：提供 32px、48px、64px，默认推荐 48px。
- 清晰定位：透明背景、抗锯齿边缘，分别校准箭头尖端、手指尖和其他操作点。
- 细线文本指针：采用 1px 深色核心线搭配浅色对比边，缩小奶蛙装饰，减少遮字。
- 便捷安装与恢复：无需管理员权限，安装前自动备份当前方案，支持恢复之前的指针。

Naiwa Cursors 🐸

A playful Naiwa-themed mouse cursor pack for Windows. Bring the goofy yellow character to your everyday clicks, text selection, dragging, and loading screens.
- 17 cursor states — Includes normal selection, links, text selection, resizing, moving, and more.
- Animated loading cursors — Looping animations for Busy and Working in Background.
- Three sizes — Available in 32px, 48px, and 64px. The default is 48px.
- Precise hotspots — Click points are aligned with arrow tips, fingertips, and other functional indicators.
- Thin text cursor — A 1px dark core with a light contrast border helps reduce text obstruction.
- Easy installation and recovery — No administrator privileges required. Your previous cursor settings are backed up before installation.
To install, fully extract the ZIP and run 安装.cmd (Install). Use the size-specific installers to choose a different size.

To restore your previous cursors, run 恢复之前指针.cmd (Restore Previous Cursors).

Designed for Windows 10 and 11. An unofficial, fan-made theme combining AI-generated artwork with pixel-level cursor refinement.
